# Mia (MIA2): 小学校低学年向け英語会話Bot の自作GPT

約4,000万パラメータの小さなGPT(10層 / 8ヘッド / 512次元、語彙16,212語)を、一から学習して作った英語会話Bot「Mia」の第2世代のコードと報告書です。
質問を3つの経路(計算・項目を読んで答える・ふつうの会話)に振り分けて答えます。

作成: マーガレットリサーチ(2026-10-28)。コードの多くはAI(Claude Code)が書きました。報告書の記録もAIが担当しています。

## 含まれるもの

| 場所 | 内容 |
|---|---|
| `MANUAL.md` | 使い方マニュアル(日本語): 準備、Botの動かし方、評価、作り直し |
| `reports/開発報告書_MIA2_2026-10-28.pdf` | 第2世代の開発報告書(10ページ)。`mia2_report.tex` が元のTeX |
| `code/` | 実行・学習・評価のスクリプト |

## 含まれないもの

- **重み(各約161MB × 3)と、項目データ・トークナイザーの束(約500MB)**: GitHubの1ファイル100MB制限に入らないため、別の置き場に置きます。取得先は `MANUAL.md` の 2.2 節に記載します(現在準備中)。
- 第1世代(2026-10-22)の報告書。第2世代の報告書は、第1世代の課題を引き継いで書かれています。
- 学習データ(TinyStories、SimpleStories)と、DeepSeekで生成した項目データ(約14MB)。配布しません。ただし評価用の固定セット(`code/benchmark/` の `read_val_entries.json`=DeepSeek生成の50項目、`chat5_set.json`、`live_set.json`)は、評価を再現するために含みます。いずれもAI生成で、誤りを含みえます。入手元は報告書の参考文献を参照してください。
- ログ、APIキー。

## 結果の読み方(重要)

報告書の数値は **単一の乱数の種の1回の結果** で、**採点の一部はLLM(DeepSeek)** です。評価問題はモデルの選択にも使っています。
値は、この一式の中でモデルを比べるための目安であり、他のモデルとの性能比較や一般的な品質の主張には使えません。
収束の確認は部分的です。報告書には、損失の途中経過、会話SFTの3エポックと5エポックの比較、強化学習の50ステップと100ステップの比較があります。一方、**エポックを増やしたときの最終指標(読解・会話テストの値)の変化と、複数の種での再現は、行っていません(未確認)**。

現在の値(2026-10-28、いずれも単一の種):

| 基準テスト | 値 |
|---|---|
| 読解(931問の正解率) | 80% |
| 会話(DeepSeek採点、100点満点) | 84.6 |
| 計算(答えの正解率) | 0.976 |
| カード全体 | 70.4%(項目にない話題の断り 65.6%) |
| 実機会話(24場面120発言、合格ライン80) | 77.9(**合格ライン未達**) |

報告書の要旨には「会話はスムーズに受け答えできる」とありますが、これは基準テストの範囲での印象です。本文のとおり、同一会話内の矛盾や、実機会話の合格ライン未達があります。

既知の弱点: 項目にない話題で、似た項目から作り話をすることが約3割あります。

## すぐ動かす

重みを取得して `code/` で展開したあと:

```
export MIA_NLAYER=10 MIA_NHEAD=8 MIA_NEMBD=512
export MIA_TOK=data/ts_v4/tokenizer_ext.json
export PYTHONPATH=.
cd code && python bot_try.py
```

詳しくは `MANUAL.md` を見てください。動作確認の環境は GPU 1枚(24GB)、Python 3.11系です。Botの実行だけならもっと小さくて済みます。

## 注意: AIが生成した内容

- Miaの返事は、小さなモデルが作った文です。**誤りや作り話を含みます**。子どもが使う場合は、大人が見てください。
- 学習・評価のデータの一部は、DeepSeek APIとQwenで生成した文です(AI生成)。学習用のデータは含みませんが、評価用の固定セット(`code/benchmark/`)はAI生成の文を含みます。
- DeepSeekおよびQwenの提供元は、この公開物を推奨・保証していません。

## 使っているもの・ライセンス

2026-10-28 に各公式ページのカードや規約で確認した内容です。法的な助言ではありません。

| 対象 | ライセンス・規約 | この一式での扱い |
|---|---|---|
| TinyStories | `cdla-sharing-1.0` | データは含まない。データを再配布するときだけ同じ条件が付く |
| SimpleStories | `mit` | データは含まない |
| Qwen3-Embedding-0.6B | `apache-2.0` | 実行時に自動ダウンロード |
| 会話データの生成に使ったQwen(基はQwen/Qwen3.8-27B) | `apache-2.0` | 出力の利用制限の記載なし |
| DeepSeek API | API規約 4.2(出力を他モデルの学習に使える) | 公開時はAI生成の明示が必要(8.1)。名前の推薦的使用は不可(5.2-5.3) |

この一式のコードと報告書のライセンス: **MIT**(`LICENSE`)。重みは別の置き場に置き、そこにも同じ条件を書きます。
