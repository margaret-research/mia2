# Mia 基準テスト (2026-10-26 オーナーと確定)

今後、モデルを比べるときは、1・2(読解・会話)に加え、3・4(計算・カード)も使う。3・4は2026-10-27にオーナーが正式な基準テストにした(旧称「補助テスト」)。テストの中身(問題・採点基準)は変えない。
読解・会話は現行Mia(または作った本体モデル)を測る。計算・カードはルーターMia・答え役Miaなど、その機能を担うモデルを測る。変えるときはオーナーと相談し、旧版との結果を並べて記録する。

## 1. 読解テスト (正解率 %)
- 問題: 学習に使っていない50項目(benchmark/read_val_entries.json、題名と本文と質問)の全質問 931問。
  型: wh 435 / yes 100 / no 99 / count 105 / unk 192。
- 方法: 項目の本文と質問を1つずつ与え、貪欲生成(温度なし、最大60トークン)で答えさせる。入力形式は `<bos> <user> Title: <題名>. <本文> Question: <質問> <bot>`。
- 判定(自動): unk は答えが "I do not know." に完全一致。他の型は、模範解答の内容語(3文字以上、the/and 等を除く)の6割以上が答えに出ていて、かつ "I do not know." でない。yes/no は先頭の Yes/No も一致。
- 実行: `MIA_NLAYER=10 MIA_NHEAD=8 MIA_NEMBD=512 MIA_TOK=data/ts_v4/tokenizer_ext.json python benchmark/eval_read.py <ckpt>` (約1分、GPUのみ・費用なし)
- 20問のテストにしたときの点: 型の配分 wh9/yes2/no2/count3/unk4 で型別の正解率を掛け合わせる。
- 注意: 判定は内容語の一致なので、人が見るより甘い(語が合えば文が崩れていても正解)。モデル間の比較用。

## 2. 会話テスト (100点満点)
- 問題: 会話SFTの検証会話から凍結した100本(benchmark/chat5_set.json: 短い会話50本=1〜4発言、長い会話50本=最初の5発言)。ユーザー発言は固定。
- 方法: Mia が貪欲生成(最大80トークン)で答える。自分の返事は会話に残す。
- 採点: DeepSeek(deepseek-chat, 温度0)が1回の返事ごとに20点: 答える8 / 覚えている6 / ことば4 / きれいさ2。
  基準は「標準的な小学校低学年(7歳)の子どもが約90点(1回18点)」。質問を無視は最大10点、矛盾・取り違えは最大12点、不適切な助言は最大8点。
  点数 = 1回あたりの平均点 × 5。短い会話・長い会話・全体の平均と、80点以上/60点未満の本数を出す。採点基準の全文は eval_chat5.py の PROMPT。
- 実行: `COST_CAP=1 MIA_NLAYER=10 MIA_NHEAD=8 MIA_NEMBD=512 MIA_TOK=<tokenizer> python benchmark/eval_chat5.py <ckpt> <タグ>` (DEEPSEEK_API_KEY が必要。bash -ic で実行。約2分、費用 約$0.07)。結果は logs/chat5_<タグ>.jsonl。
- 注意: 採点者は甘めの傾向がある。点の絶対値より、モデル間の比較に使う。
